6. FEATURED PROJECT — YOUR CURRENT ROBOT ARM

This should probably be the hero project of the entire portfolio.

Vision-Guided Mobile Robotic Arm

PERSONAL ROBOTICS PROJECT · 2025 — PRESENT

One-line description

A ROS 2-based mobile manipulation platform combining robotic arm control, autonomous navigation, perception, and embedded systems.

The problem

Building a useful autonomous robot requires more than controlling an individual actuator. The robot needs to perceive its environment, understand where it is, plan motion, control its hardware, and coordinate multiple subsystems reliably.

What I'm building

I am developing a mobile robotic platform that combines a 6-DOF robotic arm with autonomous navigation and computer vision.

Technical work

• Developing a 6-DOF robotic manipulation pipeline using inverse kinematics, trajectory planning, and MoveIt 2.

• Integrating feedback-driven actuator control for synchronized robotic motion.

• Implementing autonomous navigation using SLAM, LiDAR-based localization, sensor fusion, and obstacle-aware planning.

• Designing communication between ROS 2 nodes, embedded controllers, motor drivers, sensors, and actuator subsystems.

• Using Gazebo simulation to validate robot behavior, trajectories, and system integration before deploying to hardware.

• Working toward vision-guided manipulation so the robot can perceive and interact with objects in its environment.
